# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `global-currency`, please do not open a public issue. Instead, report security issues directly to the maintainers via GitHub private vulnerability reporting or email.

We will acknowledge receipt of your vulnerability report within 48 hours and provide a regular update on our progress toward a fix and advisory.
